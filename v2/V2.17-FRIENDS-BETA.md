# HeliLog V2.17 — Manual friends-only beta

**Current setup:** No Google sign-in, no custom domain, no custom SMTP, and no open registration. Friends sign in with accounts manually created by the HeliLog administrator. V1 production is unaffected.

## Create an account for a friend

1. Open [Supabase HeliLog TEST → Authentication → Users](https://supabase.com/dashboard/project/cabfifnsxpaalgsyicbo/auth/users). Do **not** select HeliLog Production until a separate production site is ready.
2. Choose **Add user → Create new user** (label may vary by Dashboard release). Specify the friend's own email address and a strong, **unique** starting password. When available, explicitly mark the email confirmed/auto-confirm; no invitation or SMTP message should be needed for this direct admin-created account.
3. Privately provide the friend the [HeliLog V2 test website](https://helilog-v2-test.onrender.com/) and initial sign-in credentials through a trusted channel. Do not include passwords in public posts, source code, or shared documents.
4. Friend signs in using email/password, creates their pilot profile, and starts with an empty personal logbook. Have them use fictional/test-only data while we validate private beta stability.
5. Verify account isolation by checking other accounts' aircraft, logbooks, print archives and backup snapshots are not visible. Sign out and sign in as a different pilot to confirm browser isolation.
6. If sign-in fails, first inspect the user's confirmation status and the email/password Auth provider, **without** turning on anonymous access or public signup.

## Limitations until SMTP and a domain are available

- Supabase's default mailer **cannot send verification, invitations, or password reset emails to arbitrary external friends**. Manual account creation avoids the initial invitation email, but self-service email password recovery will not reliably work for your friends without SMTP.
- The administrator should provide each person with a different high-entropy password. Never share one password across multiple friends. Plan an authenticated change-password feature or custom SMTP before using HeliLog for personal flight records, because distributing passwords manually is a temporary testing measure.
- Do not tell friends this is an approved EASA electronic logbook. Preserve original regulatory logbook records elsewhere.
- You can postpone DNS/domain and outbound email provider decisions until you're ready for a wider pilot release.
- Google OAuth was removed from all V2.17 client and candidate configurations. **If it was separately enabled in Supabase Dashboard, turn off Google under Authentication → Providers** to fully disable it at provider level.
